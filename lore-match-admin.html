API cho website

Dán URL này vào ô "Lore Match API URL" của section trên Shopify.

Các bước gắn lên store

  1. Shopify Admin, vào Online Store › Themes › Edit code. Ở thư mục Sections, thêm section lore-match và dán file lore-match.liquid.
  2. Tạo trang Find Your Fit trong Pages, mở Customize, tạo template mới và thêm section Lore Match (photo).
  3. Dán URL API ở bên trái vào ô Lore Match API URL, bấm Save.
  4. Kiểm tra domain store đã có trong mục Domain được phép gọi API ở tab Cấu hình.
  5. Đặt handle sản phẩm Shopify trùng cột Handle Shopify trong tab Catalog để thẻ gợi ý hiện ảnh, giá, size.
